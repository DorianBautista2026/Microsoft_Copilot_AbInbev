# Copilot Adoption MAZ — GitHub Pages Package

This package provides the navigation flow **Home → Index → Dashboard sections**.

## Files

- `index.html` — Home landing page and main entry point.
- `dashboard.html` — Index page with the complete executive dashboard.
- `assets/` — ONE Tech logo and social preview image.
- `404.html` — fallback redirect to Home.
- `.nojekyll` — keeps GitHub Pages from applying Jekyll processing.

## Publish

Upload the contents of this folder to the root of the repository. Do not upload the enclosing folder or only one HTML file.

In **Settings → Pages**, select **Deploy from a branch**, choose the `main` branch and the `/ (root)` folder. Then open:

`https://YOUR-USER.github.io/YOUR-REPOSITORY/`

Use the published GitHub Pages URL when sharing the dashboard.
